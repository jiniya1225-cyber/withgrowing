# 사이트 설계도(PRD) — WithGrowing

작성일: 2026-10-17 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
학교·기업·기관과 운동선수에게 멘탈 강의와 코칭을 제공하는 WithGrowing 코치의 사이트. 처음 오는 고객에게는 "어떤 코치인가"를 보여 주고, 이미 경험한 참여자에게는 소감을 남기는 창구가 된다.

## 2. 손님
- 누가 (두 부류)
  - 처음 오는 고객: 기관 교육 담당자(학교, 도서관, 체육회, 기업 등), 운동선수·운동부 관계자, 학부모
  - 이미 경험한 참여자: 강의·워크숍·코칭에 참여한 학생, 학부모, 성인
- 어디서 알고 오나
  - 처음 오는 고객: 네이버 블로그·검색, 지인·담당자 소개, 인스타그램
  - 참여자: 수업 마지막 슬라이드의 QR 코드

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 강의·코칭 주제와 내용 — 우리 대상(직원·학생·선수)에 맞는지
2. 비용·강사료 — 어떻게 정해지는지
3. 진행 방식·시간 — 몇 시간, 몇 회, 대면/비대면, 인원

## 4. 믿게 할 증거 (실제로 있는 것만)
- 코치 소개·코칭 철학 (문장은 사용자에게 받아서 그대로 — 준비 중)
- 강의 현장 사진 (실제 사진 받아서 넣기 — 준비 중)
- 코칭 자격·경력, 강의 이력 (사용자에게 받아서 그대로 적기 — 준비 중)
- 후기: 참여자가 QR로 남긴 소감 중 관리자가 승인한 것만 공개한다. 지어내거나 고쳐 쓰지 않는다

## 5. 누르게 할 버튼 하나
- 버튼 이름: 강의·코칭 문의하기 (강의·코칭 문의는 하나의 창구)
- 누르면: 문의 폼
- 보조 버튼: 카카오톡 채널로 바로 문의 (채널 주소 미정)
- 참여자용 입구는 별도: QR → 소감 작성 페이지 (메인 화면 버튼이 아니라 QR로만 들어옴)

## 6. 페이지 구성
### 메인 (위에서 아래로)
1. 첫 화면 — 한 문장 + [강의·코칭 문의하기] 버튼
2. 코치 소개 — 코칭 철학, 자격·경력, 강의 현장 사진
3. 강의 둘러보기 — 5개 주제: 멘탈코칭 / 기업가정신 / 진로 / 사회정서 / 역량
   - 주제별: 대상, 진행 방식·시간 (내용은 사용자에게 받아서 — 준비 중)
4. 공개된 소감 — 관리자가 승인한 소감만 보임
5. 비용 안내 — "대상·인원에 따라 견적을 드립니다"
6. 문의 폼 + 카카오톡 채널 버튼

### 소감 작성 (/feedback) — 휴대폰용 한 화면
- 수업 마지막 슬라이드의 QR로 바로 들어옴 → 작성 → 관리자 소감함에 쌓임

### 관리자 (/admin) — 비밀번호로 잠금
- 문의함: 들어온 문의 확인, 상태 관리(문의 → 협의 → 확정)
- 소감함: 들어온 소감 확인, 골라서 공개 승인

## 7. 폼에서 받을 것
### 강의·코칭 문의 폼
- 이름(기관명), 연락처
- 문의 종류: 멘탈코칭 / 기업가정신 / 진로 / 사회정서 / 역량 / 기타
- 희망 날짜
- 개인정보 수집·이용 동의 (필수)

### 소감 폼 (QR)
- 어떤 수업이었나요 (주제 선택)
- 소감 (자유 글)
- 이름 또는 별칭 (선택)
- 사이트에 공개해도 될까요? (동의 체크 — 동의한 소감만 공개 승인 대상)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 대상·인원에 따라 견적
- 시간: (미정)
- 위치·활동 지역: (미정)
- 연락 방법: 문의 폼, 카카오톡 채널 (채널 주소 미정)

## 9. 이번에 넣지 않을 것
- 카카오톡 알림톡(문의가 오면 카톡으로 자동 알림) — 카카오 비즈니스 채널 심사·발송 업체 가입이 필요
- 관리자에서 강의 목록 고치기 — 이번엔 5개 주제를 사이트에 직접 적어 두고, 고칠 땐 클로드에게 요청
- 참여자 경험형: 오늘의 질문, 활동지, 회차별 안내, 사전·사후 체크, 응답 모아 보기
- 콘텐츠 실험실형: 인사이트 글, 미니 자가진단, 관심 프로그램 신청, 뉴스레터 구독, 반응 분석
- 회원가입·로그인, 결제

## 10. 첫 화면 한 문장 후보
1. 가르치지 않고, 경험하게 합니다.
2. 직원·학생·선수의 멘탈을 함께 세우는 강의와 코칭
3. 무대가 교실이든, 회사든, 경기장이든 — 멘탈 강의·코칭

## 11. 다음에 할 것
- 관리자 페이지에서 강의 목록 추가·수정
- 문의가 오면 카카오톡 알림톡으로 실시간 알림 받기
- 참여자 경험형 기능 (활동지, 회차별 안내, 사전·사후 체크 → 결과 보고서에 활용)
- 콘텐츠 실험실형 기능 (인사이트 글, 자가진단, 뉴스레터)
- 코칭 철학 문장, 자격·경력·강의 이력, 현장 사진, 5개 주제별 설명 받아서 넣기
- 카카오톡 채널 주소, 활동 지역 확인

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
  - 문의 상태: 문의 → 협의 → 확정
  - 소감도 Supabase에 저장, /admin 소감함에서 공개 승인
  - 카카오톡 채널 버튼 함께
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 메인 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 문의함(상태 관리)까지 만든다
4. 소감 페이지(/feedback) → Supabase 저장 → /admin 소감함(공개 승인) → 메인에 승인된 소감 보이기
5. /feedback 주소로 QR 코드 이미지를 만들어 둔다 (수업 슬라이드용)
6. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 소감 QR · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
