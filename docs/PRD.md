# 사이트 설계도(PRD) — (사이트 이름 미정)

작성일: 2026-10-17 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
학교·기업·기관과 운동선수에게 멘탈 강의와 코칭을 제공하는 곳.

## 2. 손님
- 누가: 학교·기업·기관 교육 담당자, 운동선수(운동부가 있는 학교 관계자 포함)
- 어디서 알고 오나: 네이버 블로그·검색, 지인·담당자 소개, 인스타그램

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 강의·코칭 주제와 내용 — 우리 대상(직원·학생·선수)에 맞는지
2. 비용·강사료 — 어떻게 정해지는지
3. 진행 방식·시간 — 몇 시간, 몇 회, 대면/비대면, 인원

## 4. 믿게 할 증거 (실제로 있는 것만)
- 강의 현장 사진 (실제 사진 받아서 넣기 — 준비 중)
- 코칭 자격·경력 (자격명·경력 내용은 사용자에게 받아서 그대로 적기 — 준비 중)
- 후기: 실제 후기 있음. 받은 문장 그대로만 넣는다 (지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 강의·코칭 문의하기
- 누르면: 문의 폼
- 보조 버튼: 카카오톡 채널로 바로 문의 (채널 주소 미정)

## 6. 페이지 구성 (위에서 아래로, 한 페이지)
1. 첫 화면 — 한 문장 + [강의·코칭 문의하기] 버튼
2. 누구와 함께하나요 — 기업·기관 / 학교 / 운동선수·운동부 세 갈래
3. 강의·코칭 주제와 진행 방식 — 주제, 시간·회차, 대면/비대면, 인원
4. 강사 소개 — 자격·경력 + 강의 현장 사진
5. 후기 자리 (실제 후기를 받으면 넣음)
6. 비용 안내 — "대상·인원에 따라 견적을 드립니다"
7. 문의 폼 + 카카오톡 채널 버튼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 문의 종류: 기업·기관 강의 / 학교 강의 / 운동선수·운동부 코칭 / 개인 코칭
- 희망 날짜
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 대상·인원에 따라 견적
- 시간: (미정)
- 위치·활동 지역: (미정)
- 연락 방법: 문의 폼, 카카오톡 채널 (채널 주소 미정)

## 9. 이번에 넣지 않을 것
- 카카오톡 알림톡(문의가 오면 카톡으로 자동 알림) — 카카오 비즈니스 채널 심사·발송 업체 가입이 필요
- 회원가입·로그인
- 결제
- 블로그 글 모아 보기

## 10. 첫 화면 한 문장 후보
1. 흔들리는 순간에도 버티는 힘, 마음에서 시작합니다.
2. 직원·학생·선수의 멘탈을 함께 세우는 강의와 코칭
3. 무대가 교실이든, 회사든, 경기장이든 — 멘탈 강의·코칭

## 11. 다음에 할 것
- 문의가 오면 카카오톡 알림톡으로 실시간 알림 받기
- 사이트 이름 정하기
- 자격·경력, 현장 사진, 실제 후기 내용 받아서 넣기
- 카카오톡 채널 주소, 활동 지역 확인

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin, 카카오톡 채널 버튼 함께
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
